Where do the files go?

Obsidian + Curtis AI Chat: drop the markdown files into your vault's AI/Conversations/ folder — they're chats now, searchable and continuable with any provider. Or drop a .curt file anywhere in the vault and double-click it.

Just Obsidian: the markdown files are plain notes — put them in any folder and they read, link, and search like any other note.

Neither: keep the .curt files. One file = one conversation, portable JSON you can back up, share, and re-import later.
